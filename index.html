02 / PROCESS

花海落下，留下竹、线与纸。

从伞阵的整体气氛收束到工匠手边，每一次削、穿、裱、绘，都让一把伞慢慢成形。

02 — 工序标本 / PROCESS

六个动作，
构成一把伞的生命线。

序
01

选竹

伞骨从选竹开始。竹要直、韧、轻，能承受反复开合，又不让整把伞显得笨重。老匠人凭纹理、竹节与手感，就能判断一根竹的去留。

material · bamboo grain / dry fiber / hand inspection
02

制骨

制骨决定伞的结构精度。削篾、修边、打孔与校正都要求手上有稳定的尺度——过厚则笨重，过薄则易变形断裂。

tool · hand plane / awl / bamboo shaving
03

穿线

五色棉线穿过伞骨小孔，围绕伞头往复穿绕，多达数千针，俗称"满穿伞""网伞"。线的松紧直接改变伞面弧度与开合手感。

structure · cotton thread / radial ribs / wooden hub
04

裱面

裱面是纸与竹骨的第一次完整结合。皮纸要平整服帖，又要保留纤维的呼吸感；这一步决定了后续绘花、上油的整体观感。

surface · handmade paper / paste brush / rib shadow
05

绘花

伞面常见花鸟、山水与吉祥纹样。绘花不是表面装饰——它把一件遮雨的器物，转换为可赠礼、可陈设、可被记住的文化对象。

visual · mineral pigment / brush trace / floral motif
06

上油

桐油成膜后，伞面可以遮雨，也会形成半透明的暖色光泽。至此，纸、竹、线、画从分散的材料，变成一件完整的器物。

finish · tung oil sheen / drying canopy / warm glow

04 — 源流与传承 / LINEAGE

从唐宋走到今天的
一柄油纸伞。

在分水，老师傅常念叨这样一句话——

做伞这行，急不得。一把伞要过手九十多道，差一道，它就不是分水的伞了。
分水

如今，国家级非物质文化遗产代表性传承人 毕六福 仍坚守古法、带徒授艺； 在文创与文旅的推动下，油纸伞正从日用器物，走向收藏、装置与可被记住的文化符号。

  1. 唐宋 · 流行

    纸伞入寻常

    油纸伞雏形可上溯更早，至唐宋已在民间广泛使用，成为遮阳避雨的日常器物。

  2. 明清 · 成熟

    工艺南传入川

    制伞工艺日臻成熟，并随商贸与移民传入四川泸州一带，分水岭逐渐成为制伞集中地。

  3. 近现代 · 兴盛

    分水之名

    分水油纸伞以"满穿"伞骨与手绘伞面著称，曾是川南婚嫁与馈赠中颇有分量的物件。

  4. 2008 · 列级

    列入国家级非遗

    泸州油纸伞制作技艺入选第二批国家级非物质文化遗产名录，项目编号 Ⅷ-140。
