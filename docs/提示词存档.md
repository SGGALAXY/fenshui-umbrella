## B. 网页构建提示词（设计系统 + 需求简报）

> 这是驱动整站开发、可直接复用的"网页构建总提示词"。

```
角色：把你自己想象成一名独立摄影师 + 设计工程师，把这些 AI 生成的图当成你的摄影作品，
构建一个"摄影作品集 × 非遗档案馆"风格的网站。

主题：泸州分水油纸伞（国家级非物质文化遗产，单一非遗项目）。

【硬性要求】
- 必须使用 Bootstrap 5.3，栅格系统实现响应式（适配 PC / 平板 / 手机）。
- ≥3 种 Bootstrap 核心组件（实际：导航栏、轮播图、模态框、表单、折叠面板 共 5 种）。
- ≥2 种 JavaScript 交互（实际：导航滚动变色、阅读进度条、轮播自动播放、影像点击放大灯箱、
  工序索引滚动联动、表单校验+访客簿动态渲染、滚动揭示、知识问答 共 8 种）。
- HTML/CSS/JS 三文件分离，核心代码加中文注释，无冗余、无致命报错。
- 导航栏 ≥3 条目：缘起 / 工序 / 伞面 / 札记 / 问答 / 留言。

【视觉系统 —— 摄影集 × 档案馆】
- 底色暖宣纸 #f3ede1 + 宣纸纹理叠层；墨 #1f1a15；朱砂 #b23a2e；桐油金 #bd8a3f；深色区 #1f1a15。
- 字体：标题 Noto Serif SC（宋体）、正文 Noto Sans SC、品牌题字 Ma Shan Zheng、
  编号/图注/标签用等宽 IBM Plex Mono（档案感核心）。
- 编辑式元素：区块编号（01—、02—）、Fig.0X 图注、英文材料证据小字、细线分隔、档案编号 Ⅷ-140。
- 大图为王，图片统一做成"图版（plate）"：缩略 + Fig. 图注 + 点击放大灯箱。

【内容板块】
首页 Hero（档案编号 + Fig.01）→ 01 缘起·档案索引（ledger 卷宗 + 数据条）→ 光影轮播（PLATE Ⅰ-Ⅲ）
→ 02 工序标本（左侧吸顶索引 01-06 + 右侧大图/文字左右交错记录，每条带 Fig. 图注与英文证据）
→ 材料细部（伞头/竹骨/颜料 3 帧 Fig.08-10）→ 03 伞面影像墙（8 伞面错落拼贴，点击放大）
→ 影像分隔带（Fig.11）→ 04 传承札记（纯文字 + 折叠面板，不使用人物肖像）
→ 05 知识问答（加分游戏）→ 06 观展留言（表单 + 访客簿）→ 页脚。

【加分特色】非遗知识问答小游戏（3 题，即时反馈 + 结算评价 + 重答）。

【交付】index.html、css/style.css、js/main.js 三文件，配图引用 images/。
要求达到独立摄影师作品集 / Behance 展示级质量，浏览器控制台零报错。
```
