# 分水·寻伞 | 泸州分水油纸伞非遗文化馆

> 一柄油纸伞，撑起千年烟雨。
> Web 前端开发技术课程 · 非遗文化数字展示作品

本项目是一个聚焦 **泸州分水油纸伞**（国家级非物质文化遗产）的响应式文化展示网站，
以"现代国风 + 编辑式留白"的视觉语言，呈现油纸伞的作品之美、工艺之繁与传承之重。

---

## 一、项目主题介绍

**分水油纸伞**，流传于四川省泸州市江阳区分水岭一带，是中国传统制伞技艺的"活化石"，
2008 年泸州油纸伞制作技艺被列入**国家级非物质文化遗产名录**。
一把地道的油纸伞需历经选竹、制骨、穿线、裱纸、绘画、刷桐油等 **90 余道纯手工工序**。
民俗中"油纸"谐音"有子"，伞形圆满，寄寓团圆美满、多子多福、遮风避邪的美好祝愿。

网站以"摄影作品集 × 非遗档案馆"的方式组织，设有以下板块：

| 板块 | 内容 |
|---|---|
| 首页 Hero | 主视觉 + 档案编号 Ⅷ-140 + Fig.01 图注 |
| 01 缘起 · 档案索引 | 项目名称 / 编号 / 地域 / 寓意 卷宗式 ledger + 数据条 |
| 光影轮播 | 油纸伞三组氛围影像（PLATE Ⅰ–Ⅲ） |
| 02 工序标本 | 左侧吸顶索引 01–06 + 右侧大图/文字交错记录（选竹·制骨·穿线·裱面·绘花·上油），含 Fig. 图注与材料证据，点击放大 |
| 材料细部 | 伞头 / 竹骨 / 颜料 三帧特写（Fig.08–10） |
| 03 伞面影像墙 | 8 把不同纹样伞面错落拼贴，点击放大 |
| 影像分隔带 | 墙影一伞全幅影像（Fig.11） |
| 04 传承札记 | 纯文字 + 折叠面板（不使用人物肖像） |
| 05 知识问答 | 三题互动小游戏（加分特色功能） |
| 06 观展留言 | 留言表单 + 访客簿动态渲染 |

## 三、技术栈

- **HTML5**：语义化结构，HTML / CSS / JS 三文件分离
- **CSS3**：CSS 自定义属性（设计令牌）、Grid / Flexbox、`clamp()` 流体排版、`@media` 响应式、`prefers-reduced-motion` 无障碍
- **Bootstrap 5.3**：栅格系统 + 5 种核心组件（导航栏 / 轮播图 / 模态框 / 表单 / 折叠面板）
- **JavaScript (ES6)**：原生 JS，无额外框架；`IntersectionObserver`、`bootstrap.Modal` API 等
- **Google Fonts**：Noto Serif SC（思源宋体）/ Noto Sans SC / Ma Shan Zheng（毛笔题字）
- **部署**：GitHub Pages（公网静态托管）

### Bootstrap 组件使用（≥3，实际 5）
1. **导航栏 Navbar**（含移动端折叠）
2. **轮播图 Carousel**（自动播放 + 指示器 + 左右控制）
3. **模态框 Modal**（影像放大灯箱 + 资料来源弹窗）
4. **表单 Form**（留言表单 + Bootstrap 校验样式 + select）
5. **折叠面板 Accordion**（传承札记问答）

### JavaScript 交互效果（≥2，实际 8）
1. 导航栏滚动变色特效（透明 → 宣纸白）
2. 顶部阅读进度条
3. 轮播图自动播放（Bootstrap Carousel）
4. 影像点击放大灯箱（影像墙 + 工序图版，通用 Modal）
5. 工序索引滚动联动 + 点击平滑跳转（IntersectionObserver）
6. 留言表单校验 + 访客簿动态渲染
7. 滚动揭示动画（IntersectionObserver）
8. 非遗知识问答小游戏（加分特色功能）

## 四、AI 协同工具与应用场景

本项目为"全流程 AI 协同开发"实践，AI 仅作辅助，核心代码逻辑由团队全员理解与优化。
完整协同记录见 [`docs/AI协同记录.md`](docs/AI协同记录.md)，prompt 原文见 [`docs/prompts/`](docs/prompts/)。

| 环节 | AI 工具 | 应用场景 |
|---|---|---|
| 需求拆解 / 内容策划 | 对话式 AI | 非遗主题调研、文案初稿、板块结构拆解 |
| UI 与素材生成 | **GPT Image 2** | 生成 Hero、轮播、伞面、工序、材料细部、沉浸式背景等全套配图（25 张） |
| 代码开发与调试 | 对话式 AI | Bootstrap 布局生成、JS 交互逻辑、bug 排查、代码注释 |
| 测试与文档 | 对话式 AI | 兼容性自查、README 与答辩材料整理 |

> **合规说明**：所有 AI 生成内容均经团队审核、修改与优化（见迭代对比记录）；
> 图片为 AI 生成的示意性素材，已在页面与本文件注明；文字内容基于公开非遗资料整理，力求真实准确。

## 六、素材来源说明

- **文字内容**：基于"泸州分水油纸伞""国家级非物质文化遗产名录"等公开非遗资料整理、改写。
- **图片素材**：全部由团队使用 **GPT Image 2** AI 生成（共 25 张，位于 `images/`），
  为契合主题的**示意性艺术图像**，非真实历史照片；生成提示词完整留存于 `docs/prompts/`。
  作品伞面图采用"正面平视"构图，以规避 AI 常见的伞柄穿模问题。
- **传承板块**：采用**纯文字 + 折叠面板**呈现，**不使用任何 AI 生成的人物肖像**。
  文中提及的"毕六福"为真实存在的国家级非遗代表性传承人（仅文字客观引述，不含其肖像）。
- **字体**：Google Fonts 开源字体（Noto Serif SC / Noto Sans SC / Ma Shan Zheng）。
- **框架**：Bootstrap 5.3（MIT 协议，CDN 引入）。
